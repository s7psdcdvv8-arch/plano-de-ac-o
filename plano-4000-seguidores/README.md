# Plano 4.000 seguidores no Instagram (até 31/12/2026)

Missão 03 do Bruno: levar o @grupovilelaimoveis de 3.338 seguidores (27/10/2026) a pelo menos 4.000 até 31/12/2026, com um sistema que aprende com os resultados.

## Comece por aqui
- [2026-10-28-plano-v1.md](2026-10-28-plano-v1.md): o plano inicial completo (diagnóstico, metas, estratégia, semanas, roteiros, testes, regras, contingência, checklist, perguntas, registro).
- [painel-semanal.csv](painel-semanal.csv): meta x realizado, semana a semana.
- [registro-publicacoes.csv](registro-publicacoes.csv): cada Reel com hipótese e métricas.
- [matriz-testes.md](matriz-testes.md): status de cada teste.
- [CHANGELOG.md](CHANGELOG.md): o que mudou no plano e por quê.
- [dados/](dados/): exportações do Metricool usadas como base.

## Como atualizar (toda segunda-feira)
1. Puxar do Metricool (marca 7507729) os seguidores (ganhos, perdas) e os Reels da semana.
2. Pedir ao Bruno o print das visitas ao perfil (7 dias) do Painel profissional do app.
3. Preencher o painel e o registro; classificar cada post pela parte H do plano; acender o semáforo (parte B.3).
4. Registrar mudanças no CHANGELOG. Não apagar versões anteriores.

Os mecanismos de gancho (3.1, 3.3 etc.) são os do banco de ganchos de 21/10 (`/mnt/project-files/analises/2026-10-21-banco-de-ganchos-visuais-e-falados.md`) e da biblioteca de ganchos do repositório `conteudos-em-alta-no-imobiliario-`.
